GNAP

About this page

Grant Negotiation and Authorization Protocol (RFC 9635). This page is a client instance. It builds a grant request, proves the client key with an HTTP message signature, a JWS or a TLS client certificate, and shows what the authorization server answers. A signing key stays in this browser, and the API path forwards a request that is already signed. Mutual TLS is a property of the connection, which a browser cannot choose, so an mtls request goes through the API with the certificate and its key.

Client certificate (mtls)
About the client certificate

Used only when the proof is mtls (RFC 9635 section 7.3.2). The grant request carries the certificate as client.key.cert, and the API presents it, with this key, in the TLS handshake of that one call. The PKI page issues one. The key follows the save box above. Section 7.3.2.1 defines no key rotation for mtls.

Authorization server
About the authorization server settings

Where the grant request goes and how its proof travels. Through the API, the debugger's server forwards a request this browser already signed; from this browser, the request is sent directly and needs the server to allow it (CORS). Mutual TLS is a property of the connection, which a browser cannot choose, so the mtls proof goes through the API only.

The authorization server's grant request endpoint (RFC 9635 section 2).
How the client key is proved: an HTTP message signature (httpsig), a detached JWS (jwsd), an attached JWS (jws), or the TLS client certificate (mtls, through the API only).
Send through the debugger's API, or straight from this browser.
On the API path, do not verify the authorization server's TLS certificate. For test servers only.

Continuation
About continuation

A grant that is not finished at once returns a continue URI and token. Continue asks again, with the interact_ref when there was interaction; Revoke ends the grant. The access token's management URI rotates or revokes the token itself.

continue.uri from the response: where the grant is continued.
continue.access_token.value: presented when continuing or revoking the grant.
The access token the grant issued.
access_token.manage.uri: where the token is rotated or revoked.
access_token.manage.access_token: presented at the management URI.
