GNAP

Grant Negotiation and Authorization Protocol (RFC 9635). This page is a client instance. It builds a grant request, proves the client key with an HTTP message signature or a JWS, and shows what the authorization server answers. The private key stays in this browser. The API path forwards a request that is already signed. Mutual TLS is a property of the connection, so this page does not offer it.
