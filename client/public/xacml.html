XACML Editor

Edit an XACML 3.0 Policy or PolicySet and ask the same document for a decision. The repository lives in this browser. Nothing is sent to a server, and there is no directory behind the decision: the attributes in the request are the only ones the PDP sees. An empty deny-unless-permit policy denies every request until a rule permits one. ALFA on this page is written in the example namespace. A document pasted from anywhere else still imports.
